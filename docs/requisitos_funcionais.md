# Requisitos Funcionais

Este documento lista os requisitos funcionais (RF) do sistema IFSports, levantados durante o desenvolvimento do projeto.

| ID    | Descrição |
| ----- | --------- |
| RF01  | Gerenciar treinos esportivos por modalidade, permitindo o cadastro, edição, exclusão e consulta de treinos, incluindo eventos únicos e recorrentes, com controle de vagas e cálculo automático das ocorrências. |
| RF02  | Permitir que alunos realizem inscrição e cancelamento de inscrição em treinos, respeitando as regras de disponibilidade de vagas e os períodos definidos. |
| RF03  | Registrar e validar a participação dos alunos nos treinos, permitindo ao professor confirmar a presença e avaliar o desempenho dos participantes. |
| RF04  | Implementar um sistema de pontuação baseado na frequência, desempenho e engajamento dos alunos nas atividades esportivas. |
| RF05  | Gerar rankings e pódios por modalidade esportiva, calculados automaticamente a partir da pontuação acumulada pelos participantes. |
| RF06  | Disponibilizar aos professores funcionalidades de gerenciamento das atividades esportivas e administrativas do sistema, de acordo com seu perfil de acesso. |
| RF07  | Disponibilizar um sistema de conquistas e recompensas virtuais, incentivando a prática esportiva contínua. |
| RF08  | Disponibilizar uma seção de Perguntas Frequentes (FAQ), permitindo aos professores cadastrar, editar e remover perguntas e respostas. |
| RF09  | Disponibilizar um sistema de avisos esportivos, permitindo a criação, edição, remoção e visualização de comunicados gerais ou específicos para modalidades esportivas. |
| RF10  | Permitir autenticação segura dos usuários, incluindo cadastro, login, logout, confirmação de e-mail e redefinição de senha. |
| RF11  | Disponibilizar um sistema de notificações, permitindo informar automaticamente os usuários sobre eventos relevantes do sistema, bem como marcar notificações como lidas. |
| RF12  | Disponibilizar um mural de fotos, permitindo aos professores publicar imagens e legendas relacionadas às atividades esportivas. |
| RF13  | Disponibilizar páginas iniciais personalizadas, diferenciando a experiência de visitantes e usuários autenticados, com informações estatísticas e conteúdo esportivo. |
| RF14  | Permitir o gerenciamento das modalidades esportivas, incluindo cadastro, edição e remoção. |
| RF15  | Permitir que os usuários atualizem seus dados cadastrais, incluindo informações pessoais e foto de perfil. |
| RF16  | Disponibilizar o histórico esportivo do aluno, reunindo informações sobre participação em treinos, pontuação, conquistas e desempenho. |
| RF17  | Apresentar estatísticas sobre a prática esportiva, como percentual de participantes por modalidade e indicadores relacionados às atividades cadastradas. |
| RF18  | Disponibilizar filtros para pesquisa e consulta de treinos, permitindo localizar atividades por modalidade e situação. |
